# Beauty Hub

O **Beauty Hub** é um sistema de gestão voltado para estabelecimentos do segmento de beleza, desenvolvido para facilitar o controle de agendamentos, clientes, profissionais, vendas e acompanhamento do movimento do negócio.

O projeto foi criado com foco em organização, praticidade e experiência do usuário, reunindo em uma única plataforma funcionalidades importantes para o dia a dia de salões, estúdios e outros serviços da área de beleza.

## Sobre o projeto

O Beauty Hub permite que clientes e profissionais acompanhem e gerenciem agendamentos, além de disponibilizar ferramentas administrativas para organização do estabelecimento.

O sistema também conta com recursos de PDV, cadastro de clientes e dashboard, permitindo acompanhar informações importantes sobre o funcionamento e o movimento do negócio.

## Agendamentos

O sistema possui uma área dedicada ao gerenciamento de horários.

### Para clientes

- Visualização de horários
- Realização de agendamentos
- Acompanhamento dos próprios agendamentos

### Para profissionais

- Visualização dos agendamentos
- Organização dos horários de atendimento
- Acompanhamento da agenda de trabalho

## PDV

O Beauty Hub possui um Ponto de Venda integrado ao sistema.

O módulo foi desenvolvido para auxiliar no controle das vendas realizadas no estabelecimento e facilitar o atendimento ao cliente.

## Cadastro de clientes

O sistema permite cadastrar e organizar informações dos clientes, mantendo os dados centralizados para facilitar o atendimento e o gerenciamento do negócio.

## Dashboard

O painel administrativo permite acompanhar o movimento do estabelecimento de forma mais visual e organizada.

Por meio do dashboard, é possível consultar informações importantes para acompanhar o desempenho e a rotina do negócio.

## Objetivo do projeto

O objetivo do Beauty Hub é oferecer uma solução que centralize as principais atividades de um estabelecimento de beleza.

A proposta é reduzir a necessidade de utilizar diferentes ferramentas para controlar agenda, clientes, profissionais e vendas, reunindo essas informações em um único sistema.

O projeto também foi desenvolvido como parte da minha evolução profissional, permitindo aplicar conhecimentos de desenvolvimento web na criação de uma solução voltada para uma necessidade real de negócio.
